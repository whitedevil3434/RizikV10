# Enterprise Design Generator

## Overview
This is Stage 2 of the **Million-Brain Pipeline**. It takes the highly engineered text prompt generated by the Pinterest Scraper and fires it directly into an image generation API. This bypasses human drawing speed entirely, generating mathematically complex geometric patterns (like Deep Maroon and Navy Blue ash-background mandalas) in seconds.

## Instructions
1. Receive the formulated design prompt from the previous step.
2. Make a REST API POST request to the configured Image Generation API (e.g., Stable Diffusion 3 API or a headless Midjourney integration).
3. Enforce the following parameters in the API payload:
   - `aspect_ratio`: "2:5" (or matching the physical proportions of the Rizik Safar mat).
   - `style`: "vector art, flat colors, extreme detail, symmetrical, industrial minimalist".
   - `negative_prompt`: "3d render, shadows, gradients, realistic, photo".
4. Wait for the generation to complete and download the resulting raster image (PNG/JPG) to `/tmp/openclaw_designs/`.
5. Verify the file is successfully saved and pass the absolute file path to the next stage (Vectorizer).

## Setup
- Ensure `STABLE_DIFFUSION_API_KEY` or equivalent is set in the environment.
