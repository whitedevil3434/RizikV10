# Restrained Board tools

The normal World no longer exposes the scenario/lab picker inside the user-facing Board tools menu. `C-Link world`, `10k benchmark`, and other fixture modes remain available only when `debugWorld=1` is explicitly enabled.

The live menu now contains only camera controls, safe simulation, saved perspectives, and the World lens. This keeps the menu contextual and operational instead of making the product look like a scenario editor or visualization playground.

The MP4 is a live-tab viewport timeline.
