# Navigation versus board-context controls

This timeline compares the neutral World, the responsibility queue sheet, and the local `Board tools` disclosure.

## Findings

- The persistent rail now owns the route concept `Inbox`, while the topbar owns the contextual queue action `Queues`. The same record set is no longer presented as two identical `Inbox` labels.
- The persistent rail’s `More` means secondary board paths. The topbar’s `Board tools` means camera, safe simulation, saved views, and lens controls. Naming the scopes removes the second ambiguous “More” decision.
- The queue sheet reads as a responsibility surface, not a navigation page. `Board tools` reads as a local inspection/control disclosure, not another route menu.
- The board remains visible underneath both surfaces and neither action changes the canonical World projection.
