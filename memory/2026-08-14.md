# 2026-08-14 — C-Link 3D + motion direction

- Added `clink-platform/docs/visual-council-3d-motion-direction.md`.
- Core visual metaphor: a link under load, with five reusable objects: Expectation field, Alignment span, Evidence lens, Divergence gap, and Recovery bridge.
- Motion states are promise → evidence → divergence → recovery. The system intentionally distinguishes recorded workflow state from objective physical truth.
- CSS 3D is the default implementation; WebGL/Three.js is reserved for one shared scene; Rive/Lottie is for portable explainers.
- Motion direction preserves version history, uses causal gaps instead of alarm theatrics, and supports reduced-motion/mobile fallbacks.
